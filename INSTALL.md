# Put Santa on your Home Screen

Use the deployed **HTTPS website**, not a downloaded `index.html` file or an email/Files preview. The app also works in a normal modern browser.

## iPhone or iPad

1. Open the calendar website in **Safari**.
2. Tap **Share**.
3. Select **Add to Home Screen**. You may need to scroll through the actions.
4. Choose **Open as Web App** if offered.
5. Tap **Add**.
6. Open Santa's icon from the Home Screen. Stay online until the footer says **Ready offline**.

Menu wording can vary by iOS version. If an in-app browser lacks the Home Screen option, open the address directly in Safari.

## Android

Open the website in Chrome or another PWA-capable browser. Choose **Install app** or **Add to Home Screen** from the browser menu. The calendar's **Install** help may offer a direct installation button when the browser supports it.

## Computer

Use your browser's install icon or **Install app** option when available. Ordinary browser use works too.

## Testing a creation on your phone

Download the complete HTML file from your AI tool. In its calendar mission choose **Upload My Creation**, select the `.html` file in Files, then choose **Open My Creation**. Nothing is sent to a server. The preview is interactive and isolated; use **Back to mission** to return.

Keep the original HTML in Files or Downloads. Clearing website data, changing browsers/devices or removing the app may lose locally stored copies. A creation's own localStorage or advanced device features may be unavailable in the preview. Try the original in a computer browser when needed.

## Offline and updates

After **Ready offline**, the calendar, mission copy, artwork and saved local creations can be revisited without internet. ChatGPT itself still needs internet. An upgrade appears as **Santa has a workshop upgrade ready**; choose **Update app** when you are ready to leave any running preview. Saved stars and imported files are retained.

There are no push notifications in this release. Newly available missions are highlighted inside the calendar when you return.
